# A10 Thunder / vThunder - nastavení pro acme

acme se k zařízení přihlásí přes **aXAPI v3** (`POST /axapi/v3/auth`), naimportuje
certifikát a jeho klíč jako SSL soubory pod jménem s datem (`acme-<jméno>-<datum>-<sériové číslo>`),
mezilehlé certifikáty jednou jako soubor řetězce `acme-ca-<id>`, nasměruje na ně zadané
client-SSL šablony, ze šablon vyřadí starší položku acme, spustí `write memory` (je-li
zapnuto) a smaže starší soubory acme nad počet *ponechat*. Na konci se odhlásí.

Pro ACOS 4.1 a novější (ověřeno proti schématům aXAPI ACOS 5.2.1 a 7.0.3) na hardwaru
Thunder, vThunder i Thunder v cloudu.

## Co potřebujete

- ACOS 4.1 nebo novější s aXAPI v3 (správcovské rozhraní HTTPS).
- Síťový přístup z acme na správcovskou adresu, **TCP 443** (nebo váš port HTTPS).
- Client-SSL šablony, které mají certifikát používat, už existují (acme šablony ani
  virtuální servery nevytváří).
- Jsou-li šablony v L3V oddílu (partition): jeho jméno.

## Nastavení A10 Thunder

1. Ověřte, že je na rozhraní, kam acme přistupuje, zapnutá správa přes HTTPS
   (management rozhraní, nebo datové rozhraní s `enable-management service https`).
2. Vytvořte pro acme samostatný správcovský účet s oprávněním **write** a přístupem
   **aXAPI** (importuje soubory, mění šablony a zapisuje konfiguraci - jen čtení nestačí).
   Pro oddíl stačí oprávnění partition-write pro daný oddíl.

   ```text
   configure
   admin acme password <silne-heslo>
     privilege write
     access axapi
   exit
   write memory
   ```

   Přesné podpříkazy se mezi verzemi ACOS liší (např. `privilege partition-write` a
   přiřazení oddílu) - ověřte `admin ?` na své verzi. `access cli`/`web` nechte vypnuté,
   pokud je nepotřebujete.
3. Volitelně omezte přístup ke správcovskému rozhraní (management access listy) a
   povolte tam IP adresu serveru acme.
4. Poznamenejte si jména client-SSL šablon (`show slb template client-ssl`).

## Vyplnění v acme

| Pole v acme | Co vyplnit |
|---|---|
| Address | Správcovská IP adresa nebo DNS jméno zařízení |
| HTTPS port | `443`, pokud správa HTTPS neběží jinde |
| User | Účet z kroku 2 (výchozí `admin` - lépe samostatný účet) |
| Password | Jeho heslo |
| Partition | `shared`, nebo jméno L3V oddílu se šablonami a soubory |
| Check the device's certificate | Zapnuto; vypnout jen dokud má zařízení self-signed certifikát |
| CA certificate (pokročilé) | CA správcovského certifikátu zařízení, pokud není veřejná |
| Client-SSL templates (nasazení) | Jedno jméno šablony na řádek, např. `tpl-www-clientssl` |
| Write the configuration (nasazení) | Zapnuto: `write memory` po změně, aby přežila restart |
| Previous versions to keep (pokročilé) | Kolik starších souborů acme ponechat (výchozí 1, `-1` ponechá vše) |
| Check what is served | `www.example.com:443` - VIP, které se po nasazení ověří |

## Ověření

- Na cíli stiskněte **Try**: acme se přihlásí, přečte verzi ACOS a spočítá SSL
  certifikáty (`signed in to ..., ACOS x.y; N SSL certificate files`).
- Na zařízení po nasazení:

  ```text
  show pki cert
  show running-config slb template client-ssl <sablona>
  ```

## Časté problémy

| Problém | Řešení |
|---|---|
| `ACOS gave no signature on signing in` / 401 | Chybný uživatel nebo heslo, nebo účet nemá přístup aXAPI |
| `ACOS said ... privilege` | Účet je jen pro čtení nebo patří k jinému oddílu - dejte mu oprávnění write |
| Selže přepnutí do oddílu | Chybné jméno oddílu, nebo uživatel oddíl nesmí používat |
| Šablona nenalezena | Překlep ve jménu šablony, nebo je v jiném oddílu |
| `the older ... stays (still used?)` | ACOS nesmaže soubor, který se ještě používá; smaže se při dalším běhu |
| Chyba TLS při připojení | Zařízení má self-signed certifikát: přidejte jeho CA nebo kontrolu vypněte |
| Změna po restartu zmizí | Zapněte *Write the configuration* |
